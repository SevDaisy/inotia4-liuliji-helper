## 开发环境

手机安装 AScript APK：<https://ascript.cn/download/android/>
打开 APP，授予权限
PC端浏览器访问内网开发环境：<http://192.168.31.10:9096/>
授予 AScript 永久的录制屏幕权限：
adb shell appops set com.aojoy.airscript PROJECT_MEDIA allow
【需要 ROOT】打开自动点击器和 AScript 的无障碍辅助能力 | 列出已开启的：adb shell settings get secure enabled_accessibility_services
com.zidongdianji/com.autoclicker.clicker.accesibility.MyAccessibility
com.aojoy.airscript/com.google.android.accessibility.selecttospeak.SelectToSpeakService
adb shell settings put secure enabled_accessibility_services com.aojoy.airscript/com.google.android.accessibility.selecttospeak.SelectToSpeakService:com.zidongdianji/com.autoclicker.clicker.accesibility.MyAccessibility
查询应用版本
adb shell dumpsys package com.zidongdianji | grep versionName
授予 艾诺迪亚4 永久的显示在其他应用上层权限
adb shell appops set com.com2us.inotia4.normal.freefull.google.global.android.common SYSTEM_ALERT_WINDOW allow

## ESP32 HID

### 安装 CP2102 驱动

作用是 USB 转串口 COM（UART）,官网：<https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers?tab=downloads>
驱动安装包：<https://www.silabs.com/documents/public/software/CP210x_VCP_Windows.zip> => 转存至百度网盘

### HID 安卓蓝牙驱动

别人写好的固件，刷到 ESP32 里就好：<https://ascript.cn/hid> 屏幕中间那个大大的【下载 ESP32 固件按钮】
USB 连接板子和主机，一个一个试出来，我手上的 ESP32 好像是 ESP32-pico，记不清了，反正两块 ESP32 我都刷了这个固件

刷好了固件，手机上可以看到以 AS_ 为名字开头的蓝牙设备。配对上就好。

### HID API 文档

<http://dev.airscript.cn/docs/android/esp32>
